## Scope, carryover and verification

- Bind each candidate to the trusted owner, room, exact approved revision and currently eligible source references. Freeze it once per turn, with the same block sent once in each ModelV2 request. Take the settled/reopened conversation through the usual fresh admission. Replaying the original idempotency key observes the existing committed turn and should cause neither a room lookup for a new turn nor another model call. A different room, a denied/unknown source or a missing approved revision should receive the unchanged instructions. Treat an eligibility mismatch or read failure distinctly from an explicit no-revision result in the research evidence. [Duplicate admission checks](https://github.com/radz2291/VICT-Quellight-02/blob/14b6ccaf6f409eac3e041dc3d9abd0bb9f875344/src/lib/server/conversation/service.ts#L222-L253)
- The existing `guardDeskModel` checks persisted native context and current authority before each `doStream` or `doGenerate` call. Using the same authority for the room binding preserves that refusal if Forget or correction lands between selection and inference. An ordinary head revision update need not change native authority. Define it as a fresh-admission pin or validate the current head again at dispatch if the intended comparison includes a selection race. A context block does not grant a tool permission. [Model guard](https://github.com/radz2291/VICT-Quellight-02/blob/14b6ccaf6f409eac3e041dc3d9abd0bb9f875344/src/lib/server/desk-model-guard.ts#L14-L34)
- Room-state replacement changes the explicit block. Earlier assistant text, native observations or Working Memory under the same native authority can still carry a previously spoken statement. A matched carryover negative should deliberately echo a synthetic prior marker into a model reply, show it in ordinary memory/OM before rebase, and inspect **the entire prompt** after correction or exclusion. Native selected-context authority is stamped on generated messages. An authority change quarantines older derived messages and invalidates old OM/Working Memory selections, while original transcript access remains separate. Absence of the marker only from the first system message does not establish source exclusion.
