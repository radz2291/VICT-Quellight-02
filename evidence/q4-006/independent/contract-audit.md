# Q4-006 installed contract audit

The installed public VICT mutation result carries an operation ID, native configuration and source revisions, Observe or Reflect flags, and an inspection snapshot. `MemoryObservationView` exposes the observation as text. The checkpoint holds observation records and Working Memory. Neither shape exposes ordered group member IDs. The native stage digest covers the eligible thread messages, prior observations, Working Memory and authority revision. It does not act as a group-specific member list.

Mastra 1.28.2 strips group markup in `buildReflectorPrompt`. The captured Reflector input has parent prose, while the original observation records remain available to post-generation reconciliation. `deriveObservationGroupProvenance` matches copied nonempty lines against those parent groups and falls back by ordinal if no lines match. `combineObservationGroupRanges` then uses the first selected group's start and the last selected group's end. `wrapInObservationGroup` omits parent IDs. An interval can therefore enclose a middle parent even when the Reflector output preserves only the outer parents. Distinguish the parent notes delivered to the model, the selected parents in the controlled copied-line fixture, and the public range. These routines are in the installed `@mastra/memory/dist/src-BYrxAUzs.js` at lines 23769–23846 and 25850–25894.

The current operation read rechecks authority and masks stale result and checkpoint payloads. A captured old publication event and invocation are historical facts. Reading a current endpoint interval still requires the correct owner, room, conversation, configuration and authority, and offers only candidate membership.

The smallest additional contract for exact lineage is a versioned, per-published-group ordered list of original native message IDs, tied to the existing scoped operation, configuration and authority fields. Persist it atomically with the eligible publication. For Observe, record IDs feeding each group. For Reflect, propagate only explicitly identified parent memberships and preserve original order after deduplication. Report membership unavailable when the contributing parents or precise subgroup cannot be determined. Keep inference input scope separate from the lineage being claimed. On authority changes, retain audit identity and refuse stale member payloads until a current publication regenerates them. The list still does not establish that the generated prose is entailed by those original messages.

This investigation isolates group membership. It does not treat invocation discovery as a new requirement or conflate the product transcript's message IDs with native source IDs.
