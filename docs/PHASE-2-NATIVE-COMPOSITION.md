# Native memory composition

The app consumes reusable VICT candidate C12, source `a22615b014aa69f7501dc1504da5f9daad639786`. Its Mastra archive SHA-256 is `2d136123705f92e88a15e7e2b80e1732218ca00018c9cc55165a69a7774a84d3`; runtime remains the qualified C9 archive. Candidate C12 has 28 passing installed groups and independent review. The additional focused installed check proves ordinary observation triggers native reflection at its configured threshold. Hosted qualification belongs to the orchestrator's separate evidence.

`src/lib/server/memory/native.ts` opens the existing `quellight_memory_v2` schema with `native-thread-recoverable`, verification only. It does not import messages, create threads, query credentials or save an activation during inspection. `openQuellightMemory` returns `hosted`, `service`, `config`, `modelProfile` and the genuine `recallCapability`; callers close `hosted` without disposing their shared product stores.

Effective room/app settings supply Observer and Reflector additions, the Working Memory template and enablement, and recall additions. An absent addition keeps Mastra's native default; an explicit empty addition remains distinct. `native-policy.json` owns the short-chat observation threshold of one token, fallback history setting and provider-default generation policy. The threshold triggers extraction; it is not a generation cap. Ordinary observation handles native threshold-driven reflection. Manual reflection is reserved for an explicitly queued reflection operation.

The native configuration revision includes effective settings, the app policy, the exact installed baseline's Mastra/runtime archive identities and the recoverable adapter marker. Model routing reuses Quellight's explicit GLM-5.3-Flash constants. Without a supplied model factory, the helper installs a throwing read-only model: it produces no fallback text and makes no provider request. The automatic writer is created lazily only for an actual governed mutation.

Chat activation uses `MASTRA_RECOVERABLE_MEMORY_ADAPTER_COMPATIBILITY`, `managedContext: { id: config.id, revision: service.configurationRevision }`, ordinary history/Working Memory injection disabled, and the exact returned recall capability identity. The capability must enter the real VICT read bridge with `quellight.memory.recall` authority. The host callback enforces current-room or same-owner product scope in addition to native ownership and source exclusions.

`worker.ts` exports `createMemoryJobProcessor({ modelFactory })`, returning `process(job, stores, deadline)`. Each job retains operation ID `memory-job:${job.id}`, its original configuration and authority revision. The worker opens keyless first and reconciles an existing native operation before considering fresh inference. Prepared/completed outcomes and purge need no provider key. A new model factory is requested only after current source, policy and authority checks permit work. No app generation timer or step cap is added.

Superseded work is replaced under a short product conversation fence, using `supersedesJobId` to obtain a fresh native operation identity even when product source/configuration hashes remain unchanged. The worker verifies the queue claim before enqueueing replacement work. Native calls never run inside that product SQL transaction. Native source import remains the conversation admission owner's responsibility; the worker performs no user or assistant repair import. Unknown failures remain retryable rather than being treated as proof of failed publication.

Original chat text and generated-source eligibility are distinct. C12 retains old-authority generated replies in the transcript while excluding their IDs from future native context, recall and learning. `authority()` and `inspect()` expose `quarantinedMessageIds` separately from explicit owner exclusions. A completed chat must not be relabelled failed merely because its output was quarantined. Do not open a new thread scope solely to flush an old chat: completed public turns already perform their persistence barrier inside their original context.
