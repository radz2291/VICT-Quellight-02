Source assessment, 17 November 2026. ARA was inspected read-only at clean commit `c70e574fccde3241ab005001322d2fe734748eee`. It was not executed and its live configuration was not read. Quellight evidence below refers to the adopted C12 integration and the separately identified application tests. This is not a controlled A/B test, a quality ranking or a claim that Phase 2 reproduces all of ARA's adaptation.

**Quellight preserves the automatic approach: useful memories can be learned and used without approving each one.** The implementation changes from ARA's capture/digest/attunement pipeline to Mastra history, observations, personal working memory and governed source recall. The owner's optional correction controls are separate from ordinary automatic learning.

## What is deliberately different

ARA's attunement prompt derives **how the companion should respond to this person** from patterns, room intent, purpose and accumulated memory. It calibrates tentative interpretations and adjusts stance, directness and style. Quellight Phase 2 establishes remembered facts/preferences, scoped retrieval, editable instructions and dependable memory care. It does **not** yet recreate ARA's learned posture, derived intent or richer adaptation cycle. Those remain later product work; accurate tea recall alone cannot establish equivalent companion behavior.

This comparison supports keeping the automatic approach while qualifying a reusable VICT/Mastra foundation. It does not establish better conversational quality, lower cost, faster responses or complete ARA parity.
